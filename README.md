# Password Manager

A simple command-line Password Manager built using Python and JSON storage.

This project allows users to:

* Register new users
* Store website/app passwords
* Search existing users
* Store multiple websites for one user
* View saved credentials
* Update and delete credentials (planned)

---

# Features

* User registration
* Username existence checking
* Website existence checking
* JSON-based storage
* Object-Oriented Programming
* Separate modules/files for better structure
* CLI menu system

1. Clone the repository

```bash
   git clone <your-repo-link>
```

2. Open project folder

```bash
   cd Password-Manager
```

3. Run the program

```bash
   python main.py
```
